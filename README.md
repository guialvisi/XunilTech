# XunilTech

Portfólio da XunilTech, empresa de criação de sites fundada por três amigos que se conheceram na faculdade.

## Estrutura

- `index.html`: conteúdo e estrutura das páginas.
- `style.css`: identidade visual, layouts responsivos e animações.
- `script.js`: navegação, prévias interativas e comportamentos da interface.
- `assets/`: logos, fontes locais e suas licenças.

## Executar localmente

O site utiliza HTML, CSS e JavaScript, sem etapa de compilação ou instalação de dependências.

Na pasta do projeto, execute:

```bash
python3 -m http.server 8080
```

Abra `http://localhost:8080` no navegador.

## Conteúdo

A vitrine apresenta estudos conceituais identificados como demonstrações. Os projetos de clientes e os canais oficiais de contato podem ser incluídos posteriormente.

As animações respeitam a preferência de movimento reduzido do dispositivo. As fontes são carregadas localmente e suas licenças estão em `assets/fonts/`.
